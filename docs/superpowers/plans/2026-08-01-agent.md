# Agent Implementation Plan (Phase 6)

> Executed inline with TDD (real agent ↔ real Hub integration tests). The headless per-machine watcher that makes sync actually happen.

**Delivered (`agent/`):**

- `src/hasher.js` — sha256 matching the Hub's content hash.
- `src/config.js` — load/save `~/.synchub/config.json` (chmod 600; holds hub URL + machine token).
- `src/state.js` — persisted per-(project,file) last-known canonical hash → sent as `base_hash`.
- `src/api.js` — REST client (`getMappings`/`getManifest`/`pull`/`push`) + `pairRedeem`.
- `src/reconcile.js` — `reconcileProject`/`reconcileAll`: pull Hub-newer files, push local-only/changed; `pushLocal` handles accepted/unchanged/merged/behind/conflict (pulls merged content back); `pullOne` for live `changed` events.
- `src/watcher.js` — `chokidar` per auto-mode folder, `*.jsonl` only, debounced (~1.5s) push.
- `src/ws.js` — agent WS client with exponential-backoff reconnect.
- `src/agent.js` — orchestrates: reconcile → watch → live relay (`changed`→pull, `sync`→reconcile).
- `src/cli.js` — `pair <CODE> <hubUrl>` and `run`.
- `service/` — systemd unit, launchd plist, Windows Task Scheduler installer.
- `README.md` — pairing, run, and per-OS service install.

**Deps:** `chokidar`, `ws` (both pure-JS on this platform — no native build).

**Tests (`test/reconcile.test.js`, 2):** run the **real agent against the real Hub**
(imported from `../../hub`) over temp local folders — push local→Hub, pull Hub→local,
and pull **auto-merged** content after a divergent push. Both green.

**Deferred:** native OS toast notifications + optional Electron tray (Phase 7).
